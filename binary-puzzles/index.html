Binary Puzzles

Free printable binary puzzles in PDF — 6x6 to 12x12, with answer pages. Also known as takuzu and binairo. No sign-up, no email.

A binary puzzle is a grid you fill with nothing but 0s and 1s, and three rules do all the work: never three of the same digit in a row, an equal count of each digit in every row and column, and no two rows or columns identical. That is the entire game. There is no arithmetic and no vocabulary, which makes it one of the few logic puzzles a nine-year-old and a commuter can enjoy in the same form. Start at 6x6 and move up when the openings start feeling automatic.

Four grid sizes, each on its own page: 6x6 easy, 8x8, 10x10 and 12x12. Every sheet holds one puzzle printed with generous cells so a written 0 or 1 stays legible, plus a matching answer page with the completed grid. All PDFs are black and white and sized for a single US Letter sheet, so a whole set costs very little to print.
