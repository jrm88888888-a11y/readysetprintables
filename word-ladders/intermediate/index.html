The intermediate set uses four-letter words and five-step ladders, which is the sweet spot for 7- to 9-year-olds: long enough to need a plan, short enough to finish in a few minutes. Every word comes from a hand-checked list of real words a child at this age will know, and every ladder is verified to be solvable in exactly five steps. If a child needs a hint for each rung, use the With Clues set instead.

20 sheets, four ladders each, on US Letter, with the answer page behind every sheet. Sheets 1–10 and 11–20 use different start and end words throughout, so the two halves can be used as two separate rounds.

Frequently asked questions

What grade are these for?
2nd and 3rd grade (ages 7–9). The words are four letters long and chosen from a list a child of that age reads fluently; the easy set uses three-letter CVC words and the advanced set five-letter words.
Is there a version with clues?
Yes — the With Clues set uses the same word list and ladder length but prints a short clue beside every hidden rung, for children who need a hint or for independent work.
Are the puzzles checked?
Yes. Every word comes from a hand-checked list, and each ladder is verified in code to be solvable in exactly five steps. The answer page shows one solution; other correct ladders are possible.
Do I have to sign up?
No. Every sheet opens as a PDF straight away, and the download-all button gives you all twenty in one file.
