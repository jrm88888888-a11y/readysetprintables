Five-letter words and six-step ladders make these a real puzzle for 9- to 12-year-olds. The route is rarely obvious from the start and end words, so the child has to try a letter, check whether the result is a real word, and sometimes back up. Every word comes from a hand-checked list of real words suitable for the age, and each ladder is verified to be solvable in exactly six steps.

10 sheets, four ladders each, on US Letter, with the answer page behind every sheet. Past-tense -ed forms are excluded from the word list, so every rung is a word in its own right.

Frequently asked questions

What grade are these for?
4th to 6th grade (ages 9–12). Confident younger readers can try them; if the blank ladders are too hard, the intermediate set uses four-letter words and five steps.
Are the puzzles checked?
Yes. Every word comes from a hand-checked list, and each ladder is verified in code to be solvable in exactly six steps. The answer page shows one solution; other correct ladders are possible.
Can these be used as a class starter?
Yes. One ladder on the board takes a class about five minutes, and because several routes are usually possible it works well to collect different solutions.
Do I have to sign up?
No. Every sheet opens as a PDF straight away.
