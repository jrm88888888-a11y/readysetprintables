# Ready Set Printables

Free, no-sign-up printable coloring pages, worksheets and puzzles. The printable *is* the page:
click, download the PDF, print. No email walls, no pop-ups.

Live site: https://www.readysetprintables.com

## This repo
A self-contained static site (GitHub Pages). Everything here is generated by
`../_build/generate.py` from the source library one level up.

- `index.html`, `<section>/…/index.html` — pages
- `assets/` — style.css, preview images, thumbnails, favicon, social card, search index
- `printables/` — individual print-ready PDFs
- `downloads/` — per-gallery "download all as one PDF" files
- `sitemap.xml` — pages + image sitemap
- `CNAME` — custom domain

## Rebuild after adding content
Drop new files into the source category folders, then from the project root:

    python3 _build/generate.py --assets --maxsec=35   # repeat until it reports 0 processed
    python3 _build/generate.py --combine
    python3 _build/generate.py --html

## Deploy
Commit and push; GitHub Pages serves the repo root. `CNAME` + `.nojekyll` are included.
