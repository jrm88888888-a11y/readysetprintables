Kakuro Puzzles — 8x8

Free printable 8x8 kakuro puzzles as PDFs with answer pages. Cross-sum grids using digits 1 to 9. No sign-up and no email.

Kakuro is a crossword built out of sums. Each run of white cells has a clue number in the shaded triangle beside it, and the digits you write must add to that total, using 1 to 9 with no digit repeated inside a single run. An 8x8 grid keeps the runs short — mostly two to four cells — which means the classic forced combinations do most of the work: a 3 in two cells can only be 1 and 2, and a 16 in two cells can only be 7 and 9. Good arithmetic practice that never feels like a worksheet.

One 8x8 kakuro grid per page with the shaded clue cells split cleanly on the diagonal and the across and down totals printed at a size that stays readable. White cells are large enough for a digit plus small candidate marks. Every puzzle has an answer page with the completed grid. Black and white on US Letter, one puzzle per sheet.

Frequently asked questions

What are the rules of kakuro?
Fill the white cells with digits 1 to 9. Each horizontal run must add up to the number to its left, and each vertical run to the number above it. No digit may repeat within a single run, though the same digit can appear elsewhere in the same row if it belongs to a different run. Zero is never used.
Which combinations should I memorize first?
The unique ones. In two cells: 3 is 1+2, 4 is 1+3, 16 is 7+9, 17 is 8+9. In three cells: 6 is 1+2+3, 7 is 1+2+4, 23 is 6+8+9, 24 is 7+8+9. These are the only combinations for their length and total, so they can be written in immediately wherever they appear.
Is kakuro good for practicing mental addition?
It is one of the better puzzle formats for it, because you are constantly testing whether a set of distinct digits hits a target. It rewards knowing number bonds fluently rather than doing long calculations, so it suits a learner who has the facts but needs to use them quickly.
Do the same digits repeat across the whole grid?
Yes, freely. The no-repeat rule applies only within a single run of white cells between two shaded ones. A row can contain two 7s if they sit in different runs, which is a common source of confusion for people arriving from sudoku.
